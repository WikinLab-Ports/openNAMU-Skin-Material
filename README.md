## Material
Material Skin for openNAMU. (Based on [MDB](https://mdbootstrap.com))

Crerty에서 사용하던 Material 스킨의 openNAMU 호환 버전입니다.

개발이 중단되었습니다. 최신 openNAMU와 호환되지 않습니다.

## 사용하기
* 다운받은 폴더의 이름을 Material로 바꿔서 views 폴더에 넣어주세요.
